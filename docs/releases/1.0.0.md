# Tasktap 1.0.0

Tasktap now gives your agents, terminals and outputs a workspace of their own.
Open a project, arrange the surfaces you need, and keep the work together while
the notch stays available for the next idea or decision.

## Work inside Tasktap

- Built-in terminals with tabs, nested splits in either direction, resizable
  panes and focus mode. Your shell configuration, prompt and plugins still load.
- Open Markdown, local HTML, images, PDFs, text, audio, video and web previews
  beside the terminal. Local HTML runs in an isolated preview.
- Add, close and reopen workspaces yourself. Choose the default folder for new
  projects; existing folders stay where they are. The sidebar focuses open
  surfaces, grouped by pane.
- Eight application appearance choices, including Follow Ghostty and System,
  plus optional macOS translucency. Terminal appearance and shell prompts remain
  separate settings.

## Keep the agent conversation clear

- Review the Task, Destination and Context before sending. Focused editors keep
  your other choices; technical delivery details live in Diagnostics.
- Supported source references are captured when input starts. Switching windows
  does not silently replace the reference; refresh it explicitly when needed.
- Read compact result excerpts or the complete formatted report. Copy, narrate
  or export the selected report without accidentally using a later answer.
- Notification preferences show Tasktap enablement and macOS availability,
  including delivery errors. The notch and Activity remain available when a
  banner cannot appear.
- Cleaner settings, session lists and small-window layouts, plus smoother,
  wider Home artwork with Reduce Motion support.

The product page and user guide have been rebuilt around this workflow.

## Updating

Use **Tasktap → Check for Updates…**, or download `Tasktap-1.0.0-arm64.zip` from
this release. The optional installer accepts `bash tasktap-install.sh 1.0.0`.
Quit Tasktap before manually replacing the application.

Existing notes, history and external-terminal preferences are retained. New
installations use the built-in terminal. Closing a terminal view or workspace
leaves its process running; use **Stop session** to end it. A reboot ends those
processes.

## Requirements and current limits

Apple silicon · macOS 26+ · Python 3 for terminals · a separately installed,
signed-in agent CLI for agent work. Community builds are ad hoc signed and
**not Apple notarized**. Sparkle update archives carry an Ed25519 signature.

Claude Code and Codex have Tasktap question/report integrations. Some follow-ups
still require pasting into the original agent; review explains this before
sending. Other providers keep unsupported interactions in their terminal.
External session discovery is opt-in. Some websites block embedded previews.

Release checks cover browser and native fixtures, terminal reconnection, preview
isolation, installer replacement, package integrity and update signatures. They
include an isolated manual upgrade from the published 0.3.3 app and restoration
of its backup. Sparkle installation/relaunch, fresh-Mac permissions and a live-provider round trip for
every integration remain unverified for this release. Broader context discovery, routing evaluation and validated
artifact actions remain tracked in the implementation checklist.
