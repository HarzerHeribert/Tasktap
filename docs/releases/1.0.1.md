# Tasktap 1.0.1

Workspace controls now follow the cmux layout: each surface has its own terminal,
browser, split-right and split-down buttons. The sidebar stays compact, with one
row per workspace.

## Changes

- Removed repeated pane and tab descriptions from the workspace sidebar.
- Added a subtle attention indicator for agent questions and a checkmark for
  unread reported results. Reduce Motion disables the attention pulse.
- Moved split controls onto each surface. New terminal and browser buttons also
  target that surface; keyboard split shortcuts target the focused surface.
- Closing or moving the last tab removes its surface and collapses the divider.
  There is no surface close-all control. Closing the workspace's final tab leaves
  an empty workspace ready for another terminal, file or browser.
- Pending terminal launches have closable tabs. A late response cannot reopen a
  closed surface or replace a tab selected while the terminal was starting.
- Right-click a tab, or focus it and press Shift+F10, for Follow up, preview
  controls, session details and Move tab to…. Fixed context actions after moving
  a preview between surfaces.

## Updating

Use **Tasktap → Check for Updates…**, or download `Tasktap-1.0.1-arm64.zip` from
this release. Quit Tasktap before manually replacing the application.

Existing workspace tabs, notes, history and preferences are retained. Old empty
surfaces collapse when restored. Closing a tab keeps its terminal process
running; reopen it from Session history. Use Stop session to end a process.

Apple silicon · macOS 26+ · Python 3 for terminal sessions. Coding agents require
their installed CLI and sign-in. The community app is ad hoc signed and not Apple
notarized; the Sparkle update archive is Ed25519 signed.

Validation covers workspace browser tests and native PTY/WebKit checks for
terminal replay, layout, preview rendering and appearance. Package validation
checks archive integrity, bundled resources and the update signature, including
rejection of altered and truncated archives. Fresh-Mac permissions, Sparkle
installation/relaunch and live-provider round trips remain unverified for this
release.
