# Tasktap 1.0.2

Task review now puts your request, its destination and its reference in clear,
flat sections. Agent questions have one Reply action for typing or speech.

## Changes

- Automatic update checks now show an **Update available** badge beside Preferences
  and an arrow in the menu bar. Click to open Sparkle’s update confirmation,
  download, verify and install. Restart requires confirmation; capture, setup and
  submission guards defer it when needed. Automatic checks can be turned off.

- Reworked review with readable request text, icons, focused edit controls and
  compact destination details. The notch widens for review while staying within
  the display bounds. Required trust and delivery notices remain beside sending.
- Replaced the separate voice and discussion actions with **Reply**. The same
  agent receives your words and interprets an answer, question or constraint.
  Choices and replies settle only the displayed request; an unsent draft remains
  with its pending question.
- Added `answerKind` to agent question responses so integrations can distinguish
  choices from freeform replies. Legacy discussion events remain supported.
  Antigravity permission choices fail closed when a reply does not match an option.
- Simplified interface metadata and removed decorative separator dots.
- Rebuilt the product walkthrough around capture, prompt preparation, routing,
  replies and returning to work. The embedded terminal workspace is shown with
  real Codex and Claude Code panes in a high-resolution native capture.
- Updated the user guide, README and integration docs, with the Terminal installer
  recommended for its download checks, installation handling and backups.

## Updating

On an older version, use **Check for Updates…** in Tasktap, or run the installer.
After installing 1.0.2, future updates can appear in the new badge:

```sh
curl -fL --proto '=https' --tlsv1.2 https://harzerheribert.github.io/Tasktap/install.sh -o tasktap-install.sh && bash tasktap-install.sh
```

The installer resolves the latest stable release. For this specific version,
run `bash tasktap-install.sh 1.0.2` after downloading the script. You can also
download `Tasktap-1.0.2-arm64.zip`. Quit Tasktap before replacing the app manually.
Finish an active capture or submission before updating. Workspaces, notes,
history and preferences are retained. Closing a terminal view does not stop its
process; **Stop session** does.

Requires Apple silicon, macOS 26 or later, and Python 3 for terminal sessions.
Coding agents need their installed CLI and sign-in. The community app is ad hoc
signed and not Apple notarized; the Sparkle update archive is Ed25519 signed.

See the [release verification record](../releases.md#102-release-scope) for checks
and remaining validation limits.
