# Tasktap 1.0.3

Provider usage rings now appear in the workspace toolbar, collapsed notch and task review, sized for the existing app.

- Weekly usage fills the outer blue ring; five-hour usage fills the inner gold ring. Other reported periods retain their own labels. Click a provider for usage and reset times.
- Claude Code and Codex use existing plan logins. Google/Gemini is one indicator sourced from the signed-in Antigravity (`agy`) account, with paid tier verification and real weekly/five-hour quota.
- Added automatic paid-account checks for Cursor, Grok and GLM. Installation, API balance or a free login alone does not enable a provider. Unreadable, expired or unverified accounts remain hidden; missing quota is not estimated.
- The camera strip stays anchored while the notch opens and closes; compact review uses the same placement. Persistent meters also appear in the terminal workspace toolbar. The native panel reserves the required provider space.

Requires Apple silicon and macOS 26 or later. Existing provider CLI logins are reused; Tasktap does not purchase subscriptions. Cursor encrypted account storage requires an already accessible Cursor Safe Storage Keychain item; Tasktap never prompts for that item. The combined Google indicator requires agy 1.1.11 or newer. Provider protocol changes can make usage temporarily unavailable.

Community builds are ad hoc signed and not Apple notarized. Finish capture or submission before updating; workspaces, notes and session history are preserved.
