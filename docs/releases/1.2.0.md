# Tasktap 1.2.0

See what your agents are doing, turn a rough thought into a reviewed task, and keep the next step clear.

## Work and attention

- Embedded Claude Code, Codex, Pi and OpenCode sessions report lifecycle events through launch-scoped observers. No global hooks or extra model-generated report are installed.
- Pane headers, the workspace sidebar and the notch distinguish working, input or permission needed, an unread answer, interruption, failure and an ended process. Attention cues respect Reduce Motion.
- Activity uses compact conversation rows with grouped report history. Saved answers remain tied to their original turn. An answer or a successful process exit is not independent proof that implementation finished.
- New tasks and follow-ups ask workers to finish the authorized scope, run checks, commit their own implementation changes, and report actual commit IDs, blockers and remaining work. Review-only and no-commit requests remain respected.

## Capture and review

- Preparation runs for new tasks and follow-ups, keeps the original capture available, and presents the prepared task directly in review.
- Project and conversation context helps resolve a destination. Review shows the actual session, current status and matching evidence; ambiguous destinations ask for a choice.
- Dictation preferences now offer Apple dictation, Apple SpeechTranscriber, downloadable Whisper and optional cloud engines. Speech accounts remain separate from project-agent accounts.

## A calmer workspace

- Displays without a physical notch use a small tab attached to the top screen edge, with a soft attention glow touching its edge. Large displays use compact expanded panels; provider meters remain readable while open.
- Native menus and titlebar controls, per-terminal text size, slim scrollbars, clipboard controls, hyperlinks and tab dragging make the embedded workspace easier to use. Input and resize fixes prevent replayed or interrupted typing.
- Narrow panes keep their tabs usable and expose extra tools in the tab actions menu.
- Closing a terminal tab offers background or stop actions. Closing a workspace stops its sessions. Closing the workspace window retains the resident notch and restores the same window state when reopened.

Requires Apple silicon, macOS 26 or later, Python 3, and each selected agent's installed CLI and sign-in. Existing workspaces, notes, history and logins are preserved. Community builds are ad hoc signed, not Apple notarized.

Cursor and Antigravity have limited lifecycle monitoring. Native questions and permissions still need the terminal when no reply API is available. Live Codex and OpenCode runs were checked; fixtures and local native checks do not establish every provider/version combination or fresh-Mac permission behavior.
