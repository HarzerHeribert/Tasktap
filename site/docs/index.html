Using Tasktap

Build for Mac

You’ll need macOS 26 or newer, Xcode or the Command Line Tools with the macOS 26 SDK or newer, Git, and Python 3. For coding work, install an agent CLI and sign in to it. Local notes work on their own.

git clone https://github.com/HarzerHeribert/Tasktap.git
cd Tasktap
./scripts/build-mac.sh
open build/Tasktap.app

The script builds and locally signs the app. Open Tasktap from Finder to return to its workspace. Keep your project folders directly under ~/projects so the app can discover them.

Set up Tasktap

On a new install, setup opens before your first capture. Choose whether Tasktap should find the website or file you mention, choose how Tasktap prepares your request, pick a default coding agent and terminal, preview artwork for the notch, and choose whether an available local voice reads finished tasks aloud. Choose Save & try capture to try the shortcut with a real project. Set up later keeps the current settings and goes straight to capture.

Run it again from the Tasktap menu bar icon → Run Setup…, or from Preferences → Run setup…. You’ll start with your current choices. Back keeps your edits in the wizard; closing it discards them. Saving changes the defaults for future captures and leaves existing sessions, accounts, and model settings in place.

Your first capture

  1. Tap Control + Option + Space to type. Hold the same shortcut to dictate and release to stop. Grant microphone and speech permissions when macOS asks.
  2. Try “In Cuegrid, check that the timer still works on mobile.” Press ⌘ Return to review. Check the folder, instruction, agent and terminal. Adjust anything that looks wrong.
  3. Select Start session. The worker opens in a terminal where you can type, interrupt or answer an approval. If the folder is unclear, choose it in review or use Scratch for a new idea.

To refer to a website or file, review the proposed reference in the capture. You can change it or enter a path yourself.

Agents & accounts

In Run Setup → Tasktap, choose who turns a capture into a brief. On this Mac needs no account. Claude Code opens a visible drafting conversation in Terminal. Choose Copy & open Claude Code, paste and send the request there, then press ⌃ ⌥ Space to return. Choose Get Claude’s reply or paste a brief, edit it and review the handoff. Claude uses the account signed in to its CLI. Notes and nudges continue directly. My Codex login uses the login in your installed Codex CLI; Tasktap shows the account and workspace when Codex reports them, or identifies API-key billing. A separate ChatGPT plan connection uses the account you select for Tasktap. For Ollama, enter the server address and choose Find models, or enter the exact model ID. Downloaded models on your Mac use no cloud account; cloud models and gateways can send requests upstream.

The next step, Project work, sets the project agent and terminal independently. For example, Ollama can prepare a brief that Claude Code runs with its own login. Setup saves both choices when you finish. You can also draft in Claude Code and send the finished brief to Codex. Tasktap shows you the request before it leaves your Mac.

Who prepares the handoff?

Open Preferences → Agents → Request preparation. “On this Mac” uses the available Apple model or local matching. In setup, More connections… reveals additional model servers, provider API keys and eligible ChatGPT plan access. For automatic Claude preparation, choose an Anthropic API key or Claude Code with cloud billing. To use Ollama, vLLM or LiteLLM, choose its preset, check the base URL, find or enter a chat model, and save. A gateway can forward a request to a paid upstream provider.

The review shows the preparation route and where the worker will run. Before remote preparation, you can see the capture and matching labels to be sent and choose local preparation instead.

Who does the work?

Tasktap launches your installed Claude Code, Codex, Antigravity, Cursor CLI or Pi with its own CLI account. Under Agents → Session models, choose a fixed model or assign models by difficulty. Worker ranking can use available quota estimates. Review lets you choose the agent and model for this job. A nudge uses the existing session.

Why is the terminal asking me?

Fresh Codex workers start with Approve for me and the workspace-write sandbox. Claude Code requests Auto mode when the account and model support it. In a new Codex handoff, the trust checkbox applies to that exact folder for that launch. Claude can ask separately about folder trust. Older running workers keep the permissions they started with. If one is waiting on an approval, open its terminal to review the action. Nudges queue behind the current turn.

Return to a session

Open Workspace → Sessions. Search by project, task, agent or words from a result. Select the matching run to see its activity, handoffs and summary. Choose Open in for a live session or Resume in for a supported saved conversation.

To send a follow-up, name the session or choose Follow up. Codex can queue it on the original thread. Some agents use Copy nudge & open session; paste the reviewed text at the agent prompt.

Delivered means the nudge reached the queue. Complete carries the result. Tasktap waits for outstanding handoffs and questions to settle and checks the provider’s saved turn before closing a managed Codex or Claude worker. Each answered Codex nudge can be matched back to its own receipt. You can reopen the conversation later. Other harnesses may require reading the outcome and closing their terminal yourself.

Voice & controls

In Preferences → Voice & alerts, preview an available local Siri voice or set up Kokoro for offline English narration. Enable spoken summaries if you want to hear completions. Typed capture works in silence.

A question lights the rim around the notch. Hover or press Control + Option + J to review it. Choose an answer or Talk it through. With optional Codex Micro controls enabled in the Mac menu, the first two Agent Keys light green and red for Yes and No. The third opens discussion. The same decisions work on the Mac when the controller is unplugged.

Artwork & motion

The Mac app icon uses a still metallic voice wave across a near-black square, matching the animated artwork on this site.

Choose Glyph wave, Phase field, Relay, Signal globe or Resonator under Preferences → Appearance. Large illustrations play more slowly than compact notch signals. The microphone trace follows your voice and the relay follows handoff receipts. For still artwork and steady signals, enable Reduce motion in macOS Accessibility → Display.
