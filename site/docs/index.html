Get Tasktap for Mac

Recommended: install with Terminal. Copy this command, paste it into Terminal, and press Return. The installer checks the download, chooses the installation folder, and backs up an existing copy.

curl -fL --proto '=https' --tlsv1.2 https://harzerheribert.github.io/Tasktap/install.sh -o tasktap-install.sh && bash tasktap-install.sh

Read the installer or download the ZIP to install manually. For a specific version, run bash tasktap-install.sh 1.2.0 after downloading the script.

  1. Use macOS 26 or later on Apple silicon. Agent work also needs Python 3 and an installed, signed-in agent CLI. Notes work without an agent. You do not need Xcode for the prebuilt app.
  2. Open Tasktap from Applications. Community builds are locally signed and not Apple notarized. If macOS blocks the first launch, use System Settings → Privacy & Security → Open Anyway.
Build from source instead

Install Git, Python 3, and Xcode or Command Line Tools with the macOS 26 SDK or newer. The build creates a locally signed app.

git clone https://github.com/HarzerHeribert/Tasktap.git
cd Tasktap
./scripts/build-mac.sh
open build/Tasktap.app

Make it yours

Setup separates request preparation from project work. Choose who helps prepare a capture, then choose the installed agent and terminal that will do the work. Configure source references, artwork, and spoken results if you want them.

Choose Save & try capture, or Set up later to continue with the current settings. Revisit setup from the menu bar → Run Setup… or Preferences → Run setup….

Tasktap lives in the Dock and menu bar. Closing the workspace window leaves the notch available. Reopen from the Dock or menu; use Launch at Login there to start it when you sign in.

Arrange a workspace

Open a folder

Click + beside Workspaces. Choose Open folder…, New workspace…, or a saved workspace. A new workspace opens its first terminal; restoring a saved layout does not add another.

Preferences → Workspaces → Default workspace folder sets where new folders are created. The initial default is ~/projects. You can open an existing folder elsewhere. Changing the default keeps all existing workspaces in their original locations.

Split, move, and focus

  1. Use New task to start a reviewed agent request. Each surface has these controls: New terminal, New browser, Split right, and Split down.
  2. A workspace contains surfaces; each surface holds panes in tabs. Use its split buttons to divide that surface and open a fresh terminal. ⌘D and ⇧⌘D split the focused surface.
  3. Drag a pane’s tab to reorder it or move it into another surface. Drop on a surface edge to split the pane out; the highlight previews its destination. Press Escape or drop outside the workspace to cancel. Drag a divider to resize, or double-click to balance it. Right-click a tab, or focus it and press ⇧F10, for Move tab to…, Follow up, and preview or session actions.
  4. Focus surface temporarily expands the selected surface. Exit focus to restore the layout. Collapse the shared sidebar for more space.

The sidebar shows one row per workspace. Its folder icon gently pulses while an agent is actually working in that workspace or its corresponding project folder; an idle connection does not count as work. A gently pulsing attention mark means an agent needs your input; a checkmark means a reported result is ready. Reduce Motion disables the pulse. Opening the workspace acknowledges results; pending decisions remain until answered or withdrawn.

Copy and paste in terminal prompts

⌘V pastes clipboard text at the terminal cursor; ⌘C copies selected terminal output. Each terminal’s top bar has Copy, Paste, and text-size buttons; narrow panes keep those commands in Tab actions. Use Edit → Copy / Paste or View → Increase / Decrease / Reset Text Size from the Mac menu for the same actions. Paste respects the CLI’s bracketed-paste mode and adds no Enter key. Control-C continues to interrupt the CLI. Forms and the prompt composer keep normal text editing.

Write prompts with autocorrection

Choose Edit → Compose Text… or Tab actions → Compose text… to draft prose for any CLI. Review replacements and use Undo correction if needed, then choose Insert text. Tasktap pastes into the selected terminal without pressing Enter. Cancel keeps the draft during this app session. Multiline insertion requires protected bracketed paste; otherwise use one line. Raw terminal input keeps autocorrection off and rejects replacements of earlier text, so shell commands are not silently rewritten.

Adjust terminal text size

⌘+ (or ⌘=) increases text size in the selected terminal; ⌘− decreases it. Each press changes the size by one point, from 8 to 40 pt. ⌘0 returns that terminal to the default from Terminal preferences or appearance. Other terminals keep their own sizes. Each terminal remembers its size across tab moves and workspace restores. These controls also appear in the tab’s right-click menu.

Terminal scrollbars appear as a thin thumb while scrolling or hovering over the scrollbar. Split dividers remain a subtle line with a wider invisible hit area. Hover, keyboard focus or dragging turns only that line blue; the hit area has no outline. The pointer changes to a horizontal or vertical resize cursor and retains that cursor throughout the drag.

Pane borders follow your resize immediately; terminal text settles into its new columns when you pause or release the drag. Terminal grid changes and CLI redraws stay ordered, and recovery replays history with its recorded sizes to preserve prompt formatting. The Mac app supplies native horizontal and vertical resize cursors over dividers. VoiceOver support follows your Mac’s current setting, including changes while Tasktap is running.

Close a view without losing the process

Close tab
Use the tab’s × or ⌘W. Closing or moving the last tab also closes its surface. There is no close-all button on a surface. For a live terminal, choose Keep running in background, Stop session, or Cancel. Background sessions appear beneath their workspace in the sidebar with Working/Running, Needs input, Ready, or Failed cues. Click one to restore its panel without starting another process. Collapse the list with its disclosure button; attention remains visible on the workspace heading.
Close workspace
Confirm to stop all of this workspace’s Tasktap sessions, including background work. The workspace stays visible until its processes stop. Files, history, and layout remain saved. Restore it from + → Closed workspaces; commands are never restarted automatically.
Quit Tasktap
Embedded sessions continue while the private local terminal service remains alive.
Stop session
Right-click tab → Session details → Stop session… explicitly ends the process after confirmation.

A Mac reboot or loss of the terminal service ends processes. Tasktap does not automatically rerun commands. Scrollback is bounded; reported results and handoff history are stored separately.

Put a preview beside the terminal

Use the workspace toolbar’s + → Open file… or a surface’s New browser button. Originals stay in place. Project files reopens previously chosen files and URLs.

  • Markdown: rendered headings, lists, tables, task lists, code and local images. Related local file links open another surface.
  • Local HTML: interactive pages with inline scripts, styles and nearby assets. Source / Preview switches between the original text and the live page.
  • Images, PDFs and text: image fit/zoom, PDF page navigation, and UTF-8 text/code previews.
  • Audio and video: playback for formats supported by macOS WebKit.
  • Web: a local development server or embeddable website. Use Open in browser if the site requires your regular browser.

Refresh preview rereads a changed file. Ask agent attaches the selected file or website to a new task; review its reference before sending.

What can a preview access?

Selected local HTML runs in an isolated frame without Tasktap’s native command bridge. It can load nearby assets, but its network requests, nested frames and form submissions are blocked. Use a development-server preview or a browser for pages that require remote libraries.

Markdown does not execute embedded HTML or automatically load remote images. Local path checks constrain related resources. Web pages can refuse embedding or need login capabilities that the preview does not provide. A preview is not a full authenticated browser.

Capture a thought and review it

  1. Tap Control + Option + Space to type from any app. Hold it to dictate, then release to finish. First choose Preferences → Voice → Download & set up, then allow microphone access. Apple engines show live words; Whisper and cloud providers transcribe after release.
  2. Try “In Cuegrid, the rehearsal timer is hard to read on my phone. Make it clearer, but keep the keyboard shortcuts.” Add a sketch if it helps, then press ⌘ Return.
  3. Request preparation turns a rambling capture into a clear task while preserving your corrections and constraints. The prepared task appears directly in review. Open Original capture to compare your words, or choose Use original request to restore them in one click.
  4. Review Your request, Destination, and Reference. Use each heading’s pencil icon to edit that part. Confirm the project folder, agent, and attached page or file.
  5. Choose Start session to send the reviewed prompt to the agent in that project. New installations use Tasktap’s embedded terminal, where you can work alongside the agent in split panes and tabs. You can also save a note without launching an agent.
Edit task
Change the wording or optional project note while keeping your destination and context.
Change destination
Choose the workspace, new or existing conversation, agent, model and host.
Edit context
Change or remove the attached path, URL or sketch without silently rerouting the reviewed task.

When source references are enabled, Tasktap freezes the source URL or file path when capture begins. Switching tabs while speaking does not replace it. Review shows its origin and freshness; Refresh source deliberately reads the current source. Missing access offers manual entry.

Folder trust, concurrent work, remote preparation and manual paste appear when relevant. Sending locks the draft until Tasktap gets a response. A failed handoff preserves your text and choices for correction or retry.

Preparation checks up to eight candidate projects and sessions and three recent Tasktap handoffs. An explicit destination stays fixed. An ambiguous match asks which destination you mean. For follow-ups, Why this session? shows the match, current status, original task and session ID. Remote preparation shows this context for review before sending it; terminal contents are not read.

Diagnostics is a separate view for effective instructions, routing traces, receipt IDs and payloads. Copy or export JSON there. Connection secrets are excluded; recognizable credentials embedded in text are redacted.

Set up dictation

Preferences opens a wider window with categories on the left. Choose Voice → Dictation. The default local setup needs a one-time download of speech assets and microphone permission. Choose Try dictation to test your microphone without sending a task to an agent.

Recommended currently uses Apple dictation. In More options, choose Apple dictation, Apple SpeechTranscriber, or downloadable Whisper large-v3 Turbo. Availability depends on your Mac and language. Recommended follows future release defaults; a specific engine or cloud model stays selected across updates. An unavailable choice is kept for you to change rather than silently replaced.

Apple engines use your Mac’s preferred language unless you select another. Whisper and supported cloud models can detect the spoken language. Mixed-language accuracy depends on the engine. Original requests are preserved without automatic translation. Under Agents & connections → Reply language, choose Follow my request or English; code and documentation follow the project’s existing conventions.

For cloud dictation, choose Use a cloud provider instead and save your OpenAI, Deepgram, or ElevenLabs speech API key. Keys stay in macOS Keychain, separately from coding-agent credentials. Audio is sent to the selected provider after release and API charges apply. Local dictation never switches to cloud automatically. Downloaded Whisper runs locally after setup. Temporary recordings are removed after completion or cancellation; recording is limited to five minutes.

Downloads show progress when available and can be cancelled or retried. Typing stays available during setup. Narration is separate: turn on Voice → Read aloud → Read completion summaries aloud to select a local Siri voice or set up Kokoro.

Choose the agent and account

The agent does the project work

Tasktap launches your installed Claude Code, Codex, Antigravity, Cursor CLI, Pi or OpenCode using its own CLI authentication. OpenCode uses its configured provider and provider/model model IDs. Check installation and sign-in under Preferences → Agents & connections → Agent setup.

Session models selects the default agent, fixed or adaptive models, and terminal host. New installations use Tasktap’s embedded terminal. Existing preferences for Terminal, cmux, Ghostty, iTerm2, Warp, WezTerm or kitty remain available. Review can override one new session. Follow-ups retain the original conversation.

Codex uses its approval reviewer with the workspace-write sandbox; its review offers an exact-folder trust choice, labeled Use project settings. Claude Code requests Auto mode. Cursor CLI uses classifier-based auto review, OpenCode requests automatic permissions with its explicit denials retained, and Antigravity requests Auto execution mode. Pi’s launch-local approval trusts project resources; it is not a separate tool-approval policy. No global CLI configuration is changed. Agents may still ask about trust or permissions in their terminal. Project settings can run code. Approvals that are not forwarded remain in the agent’s own UI. The Diagnostics icon beside the review status opens handoff details for troubleshooting.

New tasks and follow-ups share the same completion instructions: finish the authorized scope, run relevant checks, make focused commits of the worker’s own implementation changes, preserve other people’s edits, and report actual commit IDs, blockers and remaining work. Review-only, planning-only and no-commit requests take precedence. Tasktap does not independently certify a worker’s implementation or commits.

From transcript to prompt

Transcription preserves your spoken words. Preparation can turn a rambling capture into a task that preserves the outcome, constraints and corrections. It runs for new tasks and follow-ups. The prepared task appears directly in review; Original capture shows your words, and Use original request restores them. Tasktap checks bounded project, session and recent-handoff context, asks when the destination is unclear, and starts the worker only after your confirmation. If the local model is unavailable, your capture is preserved and local matching remains available.

Request preparation controls who helps turn a capture into a handoff. On this Mac is the default, using local matching and the available Apple model. Other configured connections include a model server, your installed Codex login, interactive Claude Code, provider API keys and eligible ChatGPT sign-in.

Before remote preparation, Tasktap shows your capture, candidate project/session labels and up to three recent Tasktap handoffs it proposes to send and offers local preparation instead. Audio, sketch points and resolved reference attachments are excluded from that payload. Text you type or dictate can itself contain links or paths. API keys are stored in Keychain. A server or gateway may forward to a paid upstream; the project worker uses its own account independently.

Connect a model server or draft in Claude Code

For Ollama, vLLM, LiteLLM or another compatible server, choose its preset, check the base URL, then Find models. Select a chat model or enter the exact model ID, and save. Listing models sends no capture text. A local address does not guarantee local processing if the server forwards requests.

Interactive Claude preparation opens a visible CLI conversation. Choose Copy & open Claude Code, paste and send there, then return to Tasktap with Control + Option + Space. Get Claude’s reply or paste the brief, edit it, and review the destination. It uses the account signed in to that CLI.

Sessions in other apps

Preferences → Workspaces → Find sessions in other apps is off by default. Enable it to read supported apps’ local session metadata for your project folders. Tasktap’s own terminals work with discovery off; previously saved external sessions remain available.

Other apps shows each session’s original host. Open focuses an addressable session there; Details offers the available actions otherwise. Tasktap does not silently migrate or relaunch it as an embedded terminal. Capabilities depend on the host and agent, and macOS can restrict access to app data.

Return to work and read the result

Open Session history and search by project, task, agent, result or a saved session name. Open a live terminal, or explicitly resume a supported saved conversation. Automatic names may send a short excerpt of public conversation messages to the selected preparation connection; tool output and reasoning are excluded. Names refresh after messages change, at most once per session every three minutes. An unavailable model leaves the existing name in place.

Choose Follow up, or name the conversation in a capture. A supported inbox queues the nudge to that exact conversation. Otherwise, Copy nudge & open session tells you to paste the reviewed text at its prompt and press Return.

Queued, Delivered, Copied and Complete describe different evidence. A successful process exit is not a completed task. Some agents require reading the result in their original terminal.

Activity separates questions, handoffs in transit, actual work, and received reports. Reports from the same conversation share a compact row with expandable history. The notch names active tasks and projects instead of showing only a running count. A delivered follow-up does not mean its implementation is complete.

On displays without a physical notch, a small tab stays attached to the top screen edge above the menu bar. Large logical displays use a more compact panel. The soft attention glow touches the tab edge and hides when the sheet opens; Reduce Motion keeps animated indicators still.

Session details show an explicitly labeled excerpt. Read full report opens the agent’s complete text with headings, lists and code. Export summary exports that report document, not a guessed generated file. Copy, narration, export and older Activity entries keep the selected request’s report.

Externally hosted managed Claude and Codex workers can close after their handoffs settle. Embedded workers remain available until you stop them, close their workspace, or they exit. Background results can notify even while Tasktap has focus when notifications are enabled; question and result cues remain in the sidebar. A conversation you explicitly reopen stays open for direct interaction.

Know when you are needed

New embedded Claude Code, Codex, Pi and OpenCode sessions have launch-scoped lifecycle monitoring, without global hook installation or an extra generated report. Bare CLI commands in a newly opened Tasktap terminal also receive native hooks and automatic approval defaults; explicit permission flags take precedence. Help, sign-in and noninteractive subcommands retain their native behavior. Open a new terminal after updating, because existing terminals keep their original startup environment.

Pane headers show activity with a small working dot. Ordinary shells and working terminals have no colored frame. Amber means input or permission is needed, green means an unread answer, and red means failure. Attention pulses twice; new answers sweep once. Reduce Motion keeps these indicators static.

If a CLI leaves the pointer captured after exiting, choose Tab actions → Release mouse capture. Tasktap also restores terminal interaction modes and TTY settings after managed CLI exits. Reopening or reconnecting a pane restores history without sending replies to old terminal queries into the shell. Recovery preserves scrollback and sends no shell command.

Focus a pane while Tasktap is active, or open its saved answer, to acknowledge it. Opening a workspace leaves other panes unread. Session details contains copied answers by turn and timestamped events. Answer native questions and permissions in the terminal when no reply API is available. A finished turn does not independently prove task success. Cursor and Antigravity currently have limited lifecycle monitoring.

Existing and externally hosted Claude Code/Codex integrations can ask questions and report results through session-scoped tools. The pane, notch and notification open the same request. Answering settles that request once; closing it leaves it pending. Unsupported approvals remain in the terminal.

Home lists attention requests and recent reported results. Activity retains results and failures. Routine terminal output stays quiet, intentional stops do not become failure alerts, and restored results are not announced again.

Open Preferences → Notifications to enable system alerts. Tasktap’s switch is shown separately from macOS authorization, banners and Notification Center availability. Denied access links to system settings; enqueue errors remain visible.

Focus or macOS can suppress an allowed banner. Tasktap cannot confirm that it appeared. Keep using Home, Activity or the notch when system notifications are unavailable.

Voice and keyboard controls

Typed capture is always available. Apple dictation shows words as you speak and a live microphone trace; Whisper and cloud providers return text after release. In Preferences → Voice, preview an exposed local Siri voice or set up optional Kokoro for offline English narration. Spoken completions and routing narration are separate choices.

A pending question lights the notch rim. Hover for a passive peek, click to pin it, or press Control + Option + J to open a decision. Choose a displayed answer or use Reply to type or dictate in your own words. Choose Send reply to return your words to the same agent, which interprets whether you answered, asked a question or added a constraint. Sending a choice or reply settles that question; the agent can ask a new one if it needs clarification. Closing without sending preserves the pending question and your reply draft. Escape closes the topmost card. Displays without a camera cutout use a top-edge panel.

Every decision also works with the Mac’s keyboard shortcuts, pointer and voice. See the keyboard guide.

Understand the appearance layers

Application theme
Preferences → Appearance selects Follow Ghostty, Midnight, Daylight, Ocean, Dusk, Ember, Rose or System. One palette covers workspaces, terminals, forms and Preferences.
Terminal settings
Workspace actions → Terminal preferences selects the shell, text-size override and Ghostty font/cursor import. Use Reload Ghostty settings after changing its configuration.
Shell and prompt
Your shell loads its normal startup files. Oh My Zsh, aliases, plugins and Starship live here. Their configuration is independent of the workspace layout.

Tasktap draws terminals with xterm.js, not libghostty. Follow Ghostty imports supported appearance fields from the installed configuration; its keybindings, shaders and identical font shaping do not carry over. If Ghostty is unavailable, Tasktap uses a neutral fallback.

Translucent window and Blur the background use one native macOS backdrop, including the titlebar. Text remains opaque. Reduce Transparency overrides translucency. Blur can be disabled; its GPU cost has not been benchmarked.

Artwork is a separate preference: Glyph wave, Phase field, Relay, Signal globe or Resonator. Pause/play is remembered, hidden artwork pauses, and Reduce Motion uses still images and steady signals. The physical notch keeps its dark camera housing with readable controls.

Update without losing your place

The workspace and notch are separate live views. Opening capture or review in the notch keeps the workspace window, tabs and terminal output visible. Closing the workspace window leaves the notch running; clicking the Tasktap Dock icon restores the same workspace. Quit Tasktap exits the app.

Tasktap checks for updates automatically by default, on Sparkle’s daily schedule while the app is running. An Update available badge appears above Preferences, and an arrow marks the menu-bar item. Click the badge to review the version and confirm installation; Sparkle downloads and verifies the signed archive, then offers Install and Relaunch. Background checks do not restart the app.

Turn Automatically check for updates on or off in Preferences or the menu bar. Check for Updates… remains available for a manual check. Finish recording, setup, review edits or sending before restarting; Tasktap defers an unsafe restart and keeps Restart to update available. Recovered unsent text still needs its destination reviewed. Embedded terminal processes continue in the local terminal service.

Versions before 1.0.2 need a manual check or the installer to receive this feature. Previously saved automatic-check preferences remain respected.

Settings and history live under ~/Library/Application Support/Tasktap. Updating the app does not move project folders. Community signing and Sparkle signatures do not make the app Apple notarized.

Read release notes for changes and known limits. Browser previews and automated native fixtures are distinct from real provider runs; the implementation and QA plan records remaining validation.

When something gets stuck

The workspace folder is unavailable

Check that its disk is mounted and the folder still exists. Saved layouts remain available, but a missing folder cannot receive a new task. Use + → Open folder… to explicitly select its current location. Changing the default new-folder location does not move or repair existing projects.

The agent is waiting, but the notch has no question

Open the original terminal. Folder trust, native permissions and unsupported agent questions may need an answer there. Tasktap only displays questions received through a supported integration; an idle terminal is not evidence of completion.

A preview is blank or a website will not load

Use Refresh preview after changing a file. Local HTML cannot fetch remote libraries; use a development-server preview or the regular browser. Some websites block embedding or require your browser’s login. Open in browser is the fallback.

I enabled alerts but did not see a banner

Open Notification settings to check Tasktap enablement, macOS permission and banners separately. Focus can suppress an allowed banner. The exact result or failure remains in Activity; Tasktap cannot confirm visual delivery.

A session name is not changing

Names update only when conversation messages change, at most every three minutes. An unavailable preparation model leaves the current name intact. Session history searches the project, task and saved past names.

macOS will not open the app, or there are two copies

Community builds are not Apple notarized. After attempting to open the app, use System Settings → Privacy & Security → Open Anyway. Keep one installed copy in Applications. The installer checks both Applications locations and asks you to resolve duplicates before continuing.

Still stuck? Report an issue with the Tasktap version, what you tried and what happened. Inspect diagnostics before sharing them.
