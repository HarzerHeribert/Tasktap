01 / START HERE

Get for Mac

A ready-to-use Mac app. No Xcode required.

Apple siliconmacOS 26+Free community release

Get Tasktap for Mac ↗

Download the ZIP for Apple silicon, unzip it, and move Tasktap.app to Applications. macOS 26 or newer is required. You don’t need Xcode to use the prebuilt app. Agent sessions require Python 3 and a signed-in agent CLI.

Community builds are not Apple notarized. If macOS blocks the first launch, use System Settings → Privacy & Security → Open Anyway. Future updates are available from Preferences → Check for Updates….

Install with Terminal

Download and inspect the installer, then run it to install the latest stable release. You don’t need to choose a version.

curl -fL --proto '=https' --tlsv1.2 https://harzerheribert.github.io/Tasktap/install.sh -o tasktap-install.sh
less tasktap-install.sh
bash tasktap-install.sh

Press q to exit the preview. The script checks the download and installs into your home folder’s Applications, or reuses an existing installation. Open Tasktap in Finder afterward. For a specific release, use bash tasktap-install.sh 0.3.3.

After the first installation, use Tasktap → Check for Updates…. Keep the script for reinstalling or recovery.

Build from source

For development, install Git and Xcode or the Command Line Tools with the macOS 26 SDK.

git clone https://github.com/HarzerHeribert/Tasktap.git
cd Tasktap
./scripts/build-mac.sh
open build/Tasktap.app

Keep project folders under ~/projects so Tasktap can discover them.

02 / MAKE IT YOURS

Set up Tasktap

Setup opens before your first capture. Make these choices, then select Save & try capture.

  1. ReferencesChoose whether Tasktap finds the website or file you mention.
  2. Request preparationChoose the local or cloud connection that turns your words into a brief.
  3. Project workPick the coding agent and terminal that will do the work.
  4. FeedbackPreview notch artwork and choose whether a local voice reads finished tasks aloud.

Set up later keeps the current settings and takes you straight to capture.

Run it again from the Tasktap menu bar icon → Run Setup…, or from Preferences → Run setup…. You’ll start with your current choices. Back keeps your edits in the wizard; closing it discards them. Saving changes the defaults for future captures and leaves existing sessions, accounts, and model settings in place.

03 / TRY IT

Your first capture

  1. Tap Control + Option + Space to type. Hold the same shortcut to dictate and release to stop. Grant microphone and speech permissions when macOS asks.
  2. Try “In Cuegrid, check that the timer still works on mobile.” Press ⌘ Return to review. Check the folder, instruction, agent and terminal. Adjust anything that looks wrong.
  3. Select Start session. The worker opens in a terminal where you can type, interrupt or answer an approval. If the folder is unclear, choose it in review or use Scratch for a new idea.

To refer to a website or file, review the proposed reference in the capture. You can change it or enter a path yourself.

Agents & accounts

There are two separate choices: the connection that prepares your request, and the coding agent that does the project work. They can use different models and accounts.

On this Mac

Uses an available Apple model or local matching. No cloud account is needed.

Connected models

Use a CLI login, a provider account, or a model server. The route you choose determines where preparation happens.

Connection options and account details

In Run Setup → Tasktap, choose who turns a capture into a brief. On this Mac needs no account. Claude Code opens a visible drafting conversation in Terminal. Choose Copy & open Claude Code, paste and send the request there, then press ⌃ ⌥ Space to return. Choose Get Claude’s reply or paste a brief, edit it and review the handoff. Claude uses the account signed in to its CLI. Notes and nudges continue directly. My Codex login uses the login in your installed Codex CLI; Tasktap shows the account and workspace when Codex reports them, or identifies API-key billing. A separate ChatGPT plan connection uses the account you select for Tasktap. For Ollama, enter the server address and choose Find models, or enter the exact model ID. Downloaded models on your Mac use no cloud account; cloud models and gateways can send requests upstream.

The next step, Project work, sets the project agent and terminal independently. For example, Ollama can prepare a brief that Claude Code runs with its own login. Setup saves both choices when you finish. You can also draft in Claude Code and send the finished brief to Codex. Tasktap shows you the request before it leaves your Mac.

Who prepares the handoff?

Open Preferences → Agents → Request preparation. “On this Mac” uses the available Apple model or local matching. In setup, More connections… reveals additional model servers, provider API keys and eligible ChatGPT plan access. For automatic Claude preparation, choose an Anthropic API key or Claude Code with cloud billing. To use Ollama, vLLM or LiteLLM, choose its preset, check the base URL, find or enter a chat model, and save. A gateway can forward a request to a paid upstream provider.

The review shows the preparation route and where the worker will run. Before remote preparation, you can see the capture and matching labels to be sent and choose local preparation instead.

Claude Desktop handoff

For a new Claude request, you can choose Claude Desktop as the destination. Tasktap opens a prepared Code brief; confirm the folder and send it in Claude. A prepared brief is shown as Ready to send, not as running. Activity, replies, and follow-ups remain in Claude.

Who does the work?

Tasktap launches your installed Claude Code, Codex, Antigravity, Cursor CLI or Pi with its own CLI account. Under Agents → Session models, choose a fixed model or assign models by difficulty. Worker ranking can use available quota estimates. Review lets you choose the agent and model for this job. A nudge uses the existing session.

Return to a session

Find the work, even when its name has changed.

Open Workspace → Sessions. Search by project, task, agent or words from a result. Select the matching run to see its activity, handoffs and summary. Choose Open in for a live session or Resume in for a supported saved conversation.

Session details show the host app, project, and recent activity. For cmux sessions, open the original pane; if its inbox is unavailable, send your follow-up there.

Scan your workspace

Session rows separate the work, project, agent and host, status, and update time into aligned columns. Narrow windows move project and agent details below the name. Open a row to see the full session details. Projects show their folder, active sessions, and total sessions in the same compact layout.

Current and past names

Active session names follow the work described in recent public conversation messages. Tasktap uses your selected preparation connection; interactive Claude preparation uses the available on-device model instead. Cloud connections receive only a short excerpt, not tool output or reasoning. Names refresh only when messages change, at most once per session every three minutes. Open a session’s Past names dropdown to see previous names; session search includes every saved name. If a model is unavailable, the existing name stays in place.

Continue the conversation

To send a follow-up, name the session or choose Follow up. Codex can queue it on the original thread. Some agents use Copy nudge & open session; paste the reviewed text at the agent prompt.

Delivered means the nudge reached the queue. Complete carries the result. Tasktap waits for outstanding handoffs and questions to settle and checks the provider’s saved turn before closing a managed Codex or Claude worker. Each answered Codex nudge can be matched back to its own receipt. You can reopen the conversation later. Other harnesses may require reading the outcome and closing their terminal yourself.

Voice & controls

Dock and automatic startup

Click Tasktap’s Dock icon to reopen the workspace. Closing its window keeps the notch available. Choose Options → Keep in Dock from the Dock menu to retain the icon after quitting. Enable Launch at Login in Tasktap’s menu bar menu to start it when you sign in; if approval is required, Tasktap opens Login Items settings.

Voice and decisions

In Preferences → Voice & alerts, preview an available local Siri voice or set up Kokoro for offline English narration. Enable spoken summaries if you want to hear completions. Typed capture works in silence.

A question lights the rim around the notch. Hover or press Control + Option + J to review it. Choose an answer or Talk it through. With optional Codex Micro controls enabled in the Mac menu, the first two Agent Keys light green and red for Yes and No. The third opens discussion. The same decisions work on the Mac when the controller is unplugged.

Artwork & motion

The Mac app icon uses a still metallic voice wave across a near-black square, matching the animated artwork on this site.

Choose Glyph wave, Phase field, Relay, Signal globe or Resonator under Preferences → Appearance. Large illustrations play more slowly than compact notch signals. The microphone trace follows your voice and the relay follows handoff receipts. For still artwork and steady signals, enable Reduce motion in macOS Accessibility → Display.

Updates & installation

Keep one copy of Tasktap in Applications. Your settings and session history live separately in Application Support.

Choose Check for Updates… from Preferences or the Tasktap menu. Updates use Sparkle with signed archives and require your confirmation. Finish recording or sending a request before restarting. Unsaved request text is recovered after the update; review its destination again. Running terminal agents retain their helper files. The optional installer installs the latest stable release by default (or a version you specify), reuses your existing install location, and saves the previous app as a ZIP backup. Settings and history remain in Application Support.

When something gets stuck

Start with the part of the handoff that needs attention.

macOS won’t open Tasktap

Community builds are locally signed but not Apple notarized. After attempting to open the app, go to System Settings → Privacy & Security → Open Anyway.

The agent is waiting for approval

Why is the terminal asking me?

Fresh Codex workers start with Approve for me and the workspace-write sandbox. Claude Code requests Auto mode when the account and model support it. In a new Codex handoff, the trust checkbox applies to that exact folder for that launch. Claude can ask separately about folder trust. Older running workers keep the permissions they started with. If one is waiting on an approval, open its terminal to review the action. Nudges queue behind the current turn.

A session name isn’t changing

Names update only when conversation messages change, at most every three minutes. If the selected preparation model is unavailable, Tasktap keeps the current name. You can still find the session through its project or past names.

I see two copies of Tasktap

Keep one installed copy in Applications. The installer reuses an existing installation and stores the previous version as a ZIP backup. If copies exist in both Applications and your home folder’s Applications, it asks you to keep one before continuing.
